A terminal workspace with batteries included

Usage: yinz [OPTIONS] [COMMAND]

Commands:
  mother               Inspect and control this session's Mother supervisor (JSON responses)
  bubblewrap           Prepare a persistent project Bubblewrap environment (Linux)
  agent                Find, launch and control agents in explicit terminal panes
  skills               Inspect and install portable coding-agent skills
  data                 Query and atomically update the selected session's plugin data
  options              Change the behaviour of yinz
  setup                Setup yinz and check its configuration
  action               Send actions to a specific session [alias: ac]
  list-sessions        List active sessions [alias: ls]
  list-aliases         List existing plugin aliases [alias: la]
  attach               Attach to a session [alias: a]
  watch                Watch a session (read-only) [alias: w]
  kill-session         Kill a specific session [alias: k]
  delete-session       Delete a specific session [alias: d]
  kill-all-sessions    Kill all sessions [alias: ka]
  delete-all-sessions  Delete all sessions [alias: da]
  run                  Run a command in a new pane Returns: Created pane ID (format: terminal_<id>)
                       [alias: r]
  plugin               Load a plugin Returns: Created pane ID (format: plugin_<id>) [alias: p]
  edit                 Edit file with default $EDITOR / $VISUAL Returns: Created pane ID (format:
                       terminal_<id>) [alias: e]
  pipe                 Send data to one or more plugins, launch them if they are not running
  subscribe            Subscribe to pane render updates (viewport and scrollback)
  events               Stream the session's state events as JSON lines: what plugins see as
                       PaneUpdate, TabUpdate, CommandPaneExited, CwdChanged and the rest. One object
                       per line, `{"event": <type>, "payload": <the event>}`, until the session ends
  plugins              Write, check, reload and read logs of JS/TS plugins
  hooks                Install, inspect or remove coding-agent hooks
  pty-host             Inspect and clean up detached pane supervisors. Panes outlive a server that
                       was killed rather than shut down, and this is how you find them
  help                 Print this message or the help of the given subcommand(s)

Options:
      --max-panes <MAX_PANES>
          Maximum panes on screen, caution: opening more panes will close old ones
      --data-dir <DATA_DIR>
          Change where yinz looks for plugins
  -s, --session <SESSION>
          Specify name of a new session
  -l, --layout <LAYOUT>
          Name of a predefined layout inside the layout directory or the path to a layout file if
          inside a session (or using the --session flag) will be added to the session as a new tab
          or tabs, otherwise will start a new session
      --layout-string <LAYOUT_STRING>
          Raw KDL layout string to use directly (instead of a file path) if inside a session (or
          using the --session flag) will be added to the session as a new tab or tabs, otherwise
          will start a new session
  -n, --new-session-with-layout <NEW_SESSION_WITH_LAYOUT>
          Name of a predefined layout inside the layout directory or the path to a layout file Will
          always start a new session, even if inside an existing session
  -c, --config <CONFIG>
          Change where yinz looks for the configuration file [env: YINZ_CONFIG_FILE=]
      --config-dir <CONFIG_DIR>
          Change where yinz looks for the configuration directory [env: YINZ_CONFIG_DIR=]
  -d, --debug
          Specify emitting additional debug information
  -h, --help
          Print help
  -V, --version
          Print version
